L'objectif du projet est d'automatiser les selectmenu afin d'éviter de le recréer a la main, on va les appeler les selecteurs


# Premiére instalation
Pour votre premiére instalation du projet, voici comment le realiser : 

- sur le terminal , écrivez 
```bash
git clone "https://github.com/HutchAlpha/SelectMenuPlugins.git";
```

Cela permettra de telecharger le projet sans devoir créer votre dossier vous même

- ensuite instalons REACT
```bash
npm create vite@latest my-react-app -- --template react;
```

# Lancer le Front

```bash
cd my-react-app
npm run dev
```
